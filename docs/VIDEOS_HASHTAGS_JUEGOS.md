# Videos, hashtags, descarga y juegos

## Crear publicación
- Texto + #hashtags
- Video opcional (máx. 24 minutos)
- Switch Permitir descarga

## Descarga
Solo si allow_download = true → botón en la tarjeta del post.

## Hashtags
Extraídos del texto y del campo extra. Menú lateral → Explorar #temas.

## Secciones (admin)
Drawer → Añadir sección (tabla app_sections).

## Juegos
Pestaña Juegos → Subir juego → is_approved = false hasta que admin apruebe.

Ejecutar supabase/schema_v3.sql
